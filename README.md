# Tweet2Share

> Turn X (Twitter) posts into beautiful, shareable images.

**Tweet2Share** 是一个轻量级的推文图文整理与分享工具。用户只需粘贴一条 X（Twitter）公开推文链接，即可提取推文文字、作者信息和配图，并将内容整理成一张或多张适合保存、分享的图片。

项目希望解决一个简单的问题：**让值得收藏的推文，不再需要手动截图、下载图片和反复排版。**

> **项目状态：早期规划 / 开发中**
>
> 当前仓库处于项目初始化阶段。下方功能列表描述的是产品目标与开发计划，不代表这些功能已经全部实现。

## ✨ 核心目标

- **链接导入**：通过推文链接快速导入公开内容。
- **文字提取**：整理推文正文、作者名称、用户名等信息，并尽可能保留原有段落与换行。
- **图片提取**：获取推文中的图片资源，尽可能使用原始图片，而不是通过页面截图获取。
- **原图优先**：保留图片宽高比例和清晰度，避免不必要的裁切、拉伸或压缩。
- **顺序还原**：按照原推文中的内容顺序展示文字与图片。
- **自动排版**：将文字和图片组合成清晰、简洁、易阅读的分享图文。
- **图片导出**：支持导出 PNG，长内容可考虑自动生成长图或分页图片。

## 🧩 预期使用流程

1. 复制一条 X（Twitter）推文链接。
2. 打开 Tweet2Share，粘贴链接并开始解析。
3. 预览提取到的正文、作者信息和图片。
4. 调整或确认图文排版。
5. 导出图片，保存或分享到其他平台。

**核心体验：复制链接 → 自动提取 → 自动排版 → 导出分享。**

## 🎨 设计原则

| 原则 | 说明 |
| --- | --- |
| 简单易用 | 尽量减少操作步骤，让用户专注于内容本身 |
| 原图优先 | 尽可能获取原始图片资源，避免二次截图 |
| 内容完整 | 保留正文、图片及其对应关系和排列顺序 |
| 尊重比例 | 图片不随意裁切或拉伸，优先按原比例展示 |
| 排版克制 | 以清晰、易读为主，避免过度装饰 |
| 轻量化 | 优先采用简单直接的 Web 使用体验 |
